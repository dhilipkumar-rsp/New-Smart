# Smart Attendance System

An intelligent web-based attendance management system designed for educational institutions. This system provides a modern, responsive interface for students, teachers, and administrators to manage attendance efficiently.

## Features

### 🎯 Core Functionality
- **User Authentication**: Secure login system with role-based access (Student, Teacher, Admin)
- **Real-time Attendance Tracking**: Mark attendance with timestamp and location data
- **Dashboard Analytics**: Visual statistics showing attendance rates and trends
- **History Management**: View comprehensive attendance history
- **Admin Panel**: Complete user management and reporting capabilities

### 💻 Technical Features
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Local Storage**: Data persistence using browser localStorage
- **Modern UI/UX**: Clean, intuitive interface with smooth animations
- **Real-time Updates**: Live data updates and notifications
- **Geolocation Support**: Optional location tracking for attendance verification

## Quick Start

1. Open `index.html` in your web browser
2. Use the demo credentials to test different user roles:
   - **Student**: `student/student123`
   - **Teacher**: `teacher/teacher123`
   - **Admin**: `admin/admin123`

## User Roles

### 👨‍🎓 Student/Teacher Dashboard
- View attendance statistics (total days, present days, attendance rate)
- Mark daily attendance with location tracking
- View detailed attendance history
- Real-time notifications and feedback

### 👨‍💼 Admin Dashboard
- **User Management**: View all users and their attendance rates
- **Reports & Analytics**: Comprehensive attendance reports and statistics
- **Performance Tracking**: Monitor attendance trends across the institution

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with responsive design and animations
- **Icons**: Font Awesome for professional iconography
- **Storage**: Browser localStorage for data persistence
- **Architecture**: Single-page application (SPA) with modular JavaScript

## Installation

No installation required! Simply:

1. Clone the repository
2. Open `index.html` in any modern web browser
3. Start using the system with the provided demo credentials

For development or hosting:
```bash
# Start a local server (optional)
python3 -m http.server 8000
# Navigate to http://localhost:8000
```
